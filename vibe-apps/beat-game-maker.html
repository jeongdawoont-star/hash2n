박자게임 메이커

낱말을 넣으면 목소리와 음악을 박자에 맞춰 넣은 세로 영상을 만들어요. 뒤로 갈수록 비슷한 발음의 낱말이 끼어들어 헷갈려요.

구글 API 키

무료 키는 분당 호출 한도에 걸리면 자동으로 기다렸다가 이어서 만들어요. 낱말을 8~12개 이내로 두면 빨라요.

키는 구글 서버에 음성을 요청할 때만 쓰여요. 발급은 aistudio.google.com/apikey 에서 해요.

낱말

쉼표나 줄바꿈으로 나눠요. 앞부분에서는 이 낱말만 차례로 반복돼요.

뒤로 갈수록 더 자주 끼어들고, 발음이 가까운 낱말부터 골라요.
