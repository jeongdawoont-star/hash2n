🛫 학생 라운지 연동 가이드 & 매뉴얼

✨ 자리배치와 학생 라운지가 실시간으로 연결됩니다!

선생님이 자리배치에서 주는 칭찬 점수와 머쓱 점수가 구글 Firebase(Firestore)를 통해 학생들의 폰/태블릿 라운지(주식·마니또·대회·담벼락)로 실시간 전달됩니다. 반대로 라운지에서 선생님이 승인한 주식 환전이나 태도 감점도 자리배치 점수판에 자동으로 기록됩니다.

1 Firebase 프로젝트 & Firestore 무료 생성 (1분 소요)

구글 무료 계정만 있으면 신용카드 등록 없이 1분 만에 데이터베이스를 만들 수 있습니다.

① 🔥 Firebase 콘솔 열기 ↗ 로 이동해 구글 로그인 후 [프로젝트 만들기]를 누릅니다. (이름: 예 `우리반라운지` 등 자유롭게)
② Google 애널리틱스는 체크 해제(권장)하고 만들기 완료합니다.
③ 왼쪽 메뉴 [빌드] → [Firestore Database]를 누르고 [데이터베이스 만들기]를 클릭합니다.
④ 데이터베이스 위치는 asia-northeast3 (서울) 또는 기본값을 선택합니다.
⑤ 보안 규칙 단계에서 [테스트 모드에서 시작]을 체크하고 [사용 설정]을 누르면 완성!
2 웹 앱 설정 키 복사해서 붙여넣기
① Firebase 콘솔 상단 [프로젝트 개요] 옆의 ⚙️ [프로젝트 설정]을 클릭합니다.
② 화면 맨 아래 '내 앱' 섹션에서 웹 아이콘 </>을 클릭합니다.
③ 앱 닉네임(예: `라운지`)을 적고 [앱 등록]을 누릅니다.
④ 화면에 나타나는 코드(스니펫)를 통째로 복사합니다.
💡
통째로 붙여넣어도 문제 없습니다!
import { initializeApp }... 같은 영어가 섞인 전체 코드를 복사해서 퍼스트클래스 'Firebase 설정' 칸에 그대로 붙여넣으셔도 프로그램이 알아서 필요한 핵심 키(apiKey, projectId 등)만 쏙 뽑아 자동으로 정리해 드립니다.
3 학급 코드 정하고 [저장] 누르기
① 학급 코드: 다른 학교나 학급과 겹치지 않는 고유한 영문/숫자 코드(예: bupyeong5-1-2026)를 입력합니다.
② [저장] 버튼을 누르면 설정이 보관되고, 상태창에 '자동 보내기 켜짐 ✓'이 뜹니다.
③ [지금 보내기]를 누르면 현재 자리배치와 명단, 점수가 라운지로 즉시 1차 전송됩니다.
4 학생 라운지 열기 & 학생들에게 QR 배포
① [학생 라운지 열기 ↗]를 누르면 방금 저장한 설정이 라운지에 자동으로 연결되어 열립니다.
② 라운지 화면 우측 상단의 ⚙️(선생님 모드)에서 QR코드를 교실 TV 화면에 띄우거나 인쇄해 교실에 붙입니다.
③ 학생들은 스마트폰 카메라나 태블릿으로 QR을 찍고, 출석번호와 생일(비밀번호 6자리)로 로그인하면 끝납니다!

❓ 자주 묻는 질문 & 안심 팁

Q. 혹시 요금이 청구될 위험이 있나요?
절대 없습니다. 구글 무료 플랜(Spark)은 하루 읽기 5만 회, 쓰기 2만 회가 매일 무료로 제공되어 학급 단위에서는 초과할 일이 전혀 없습니다. 신용카드 등록도 요구하지 않습니다.
Q. Firestore 생성 후 30일 뒤 만료 경고 메일이 와요!
테스트 모드로 생성하면 30일 임시 기간이 지정됩니다. 1년 내내 유지하려면 Firebase 콘솔 → Firestore → [규칙(Rules)] 탭에서 조건을 지우고 allow read, write: if true; 로 바꾼 뒤 [게시]를 누르시면 됩니다.
