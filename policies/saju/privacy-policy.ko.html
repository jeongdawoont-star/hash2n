영통사주 개인정보처리방침

시행일: 2026년 10월 6일 · 개발자: Hashbrown Studio · 앱 패키지: com.vivecoding.saju

Hashbrown Studio(이하 "개발자")는 영통사주 앱(이하 "앱")을 이용하는 분의 개인정보를 소중히 다룹니다. 앱은 회원가입이 없고, 개발자가 운영하는 서버가 없으며, 이용자의 정보를 개발자가 수집·보관하지 않습니다.

1. 앱이 다루는 정보

항목용도저장 위치
생년월일·태어난 시각·양력/음력·성별사주 원국 계산 및 AI 사주 풀이앱 실행 중 메모리(저장하지 않음)
상담 질문 내용AI 답변 생성앱 실행 중 메모리(저장하지 않음)
Google AI(Gemini) API 키이용자 본인의 AI 이용 인증이용자 기기 내부
음성 입력(마이크)말로 생년월일·질문 입력앱이 녹음 파일을 저장하지 않음

2. 제3자 전송

AI 사주 풀이와 음성 합성을 위해, 이용자가 입력한 생년월일 정보와 질문은 이용자 본인의 API 키로 Google LLC의 Gemini API(generativelanguage.googleapis.com)에 암호화(HTTPS)되어 직접 전송됩니다. 개발자는 이 내용을 중간에서 받거나 볼 수 없습니다. Google의 데이터 처리는 Gemini API 추가 서비스 약관과 Google 개인정보처리방침을 따릅니다. 무료 등급 API 키를 사용할 경우 Google이 서비스 개선을 위해 입력 내용을 활용할 수 있으니, 민감한 개인정보(실명, 연락처 등)는 질문에 넣지 마세요.

음성 입력은 기기에 설치된 Android 음성 인식 서비스(일반적으로 Google)가 처리하며, 앱은 변환된 텍스트만 받습니다.

3. 권한

  • 마이크(RECORD_AUDIO): 음성으로 입력할 때만 사용합니다. 거부해도 글자 입력으로 모든 기능을 이용할 수 있습니다.
  • 인터넷: Google AI 서버와 통신합니다.
  • 진동: 전화 수신 연출에 사용합니다.

4. 보관 및 삭제

생년월일과 상담 내용은 앱을 닫으면 사라지며, "정보 리셋" 버튼으로 언제든 바로 지울 수 있습니다. 기기에 저장되는 것은 API 키와 화면 설정뿐이며, 앱의 "변경" 버튼으로 키를 바꾸거나 앱 데이터 삭제·앱 삭제로 지울 수 있습니다. 개발자 서버에는 어떤 정보도 남지 않으므로 별도 삭제 요청 절차가 필요 없습니다. 사주풀이 족자 이미지는 이용자가 저장·공유를 선택할 때만 기기에 저장됩니다.

5. 아동

앱은 만 18세 이상 이용자를 대상으로 하며, 아동의 정보를 의도적으로 수집하지 않습니다.

6. 오락 목적 고지

앱의 사주 풀이는 AI가 생성한 오락용 콘텐츠이며, 의료·법률·재정 등 중요한 결정의 근거가 될 수 없습니다.
