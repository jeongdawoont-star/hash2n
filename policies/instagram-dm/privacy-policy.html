개인정보처리방침

시행일: 2026-10-25
적용 서비스: 인스타DM (Meta 앱 이름 인스타DM-IG) — 인스타그램 계정 @hash2n의 댓글 자동 답장 서비스
운영자: 해시브라운(hash2n)

본 방침은 운영자가 자신의 인스타그램 계정 @hash2n에서 이벤트·앱 무료 코드 안내를 위해 사용하는 자동 답장 서비스(이하 "서비스")가 이용자 정보를 어떻게 다루는지 설명합니다. 서비스는 @hash2n 게시물에 댓글을 단 이용자에게 인스타그램 DM으로 안내 메시지와 링크 또는 무료 코드를 보냅니다. 서비스는 Meta의 Instagram API를 통해서만 동작하며, 이용자의 인스타그램 비밀번호에는 접근하지 않습니다.

1. 처리하는 정보

이용자가 @hash2n 게시물에 댓글을 달거나, 서비스가 보낸 DM의 버튼을 누르면 Meta가 다음 정보를 서비스에 전달합니다.

  • 인스타그램 사용자 식별번호(앱 범위 ID)와 사용자 이름(아이디)
  • 댓글 내용, 댓글 ID, 댓글이 달린 게시물 ID, 작성 시각
  • DM 버튼 클릭 정보(어떤 버튼을 눌렀는지)와 시각
  • 서비스가 보낸 DM의 발송 결과(성공·실패)와, 무료 코드를 보낸 경우 어떤 코드를 보냈는지

이름·전화번호·이메일·위치 등 위에 적지 않은 정보는 수집하지 않습니다.

2. 이용 목적

  • 댓글을 단 이용자에게 요청한 안내·링크·무료 코드를 DM으로 보내기
  • 같은 사람에게 중복 발송하지 않고, 이미 받은 사람이 다시 요청하면 같은 코드를 다시 보내기
  • 무료 코드가 누구에게 몇 개 나갔는지 관리하고, 발송 오류를 확인하기

위 목적 외의 광고·마케팅·프로파일링에는 사용하지 않으며, 정보를 판매하지 않습니다.

3. 보관 장소와 기간

  • 발송 기록은 운영자가 관리하는 컴퓨터의 데이터베이스에 저장됩니다.
  • 무료 코드 발급 기록(코드, 사용자 식별번호, 사용자 이름, 발송 시각)은 운영자의 Google 스프레드시트에 저장됩니다.
  • 정보는 해당 이벤트가 끝난 뒤 최대 1년까지 보관하고 삭제합니다. 이용자가 삭제를 요청하면 아래 절차에 따라 바로 삭제합니다.

4. 제3자 제공 및 처리 위탁

  • Meta Platforms(Instagram) — 댓글 알림 수신과 DM 발송에 사용합니다. Meta의 처리에는 Meta 개인정보처리방침이 적용됩니다.
  • Google(Google 스프레드시트) — 무료 코드 발급 기록 보관에 사용합니다.

그 밖의 제3자에게 정보를 제공하지 않습니다.

5. 안전성 확보

서비스는 Meta가 서명한 요청만 처리하며, 관리 화면은 외부 인터넷에 공개하지 않습니다. 접근 토큰 등 비밀값은 운영자의 컴퓨터에만 보관합니다.

6. 아동의 개인정보

서비스는 인스타그램 이용 가능 연령의 이용자를 대상으로 하며, 아동의 정보를 의도적으로 수집하지 않습니다.

7. 방침의 변경

처리하는 정보나 목적이 바뀌면 본 방침을 갱신하고 상단의 시행일을 변경합니다.

8. 문의

개인정보 관련 문의: doldown@naver.com · 인스타그램 @hash2n DM

9. 데이터 삭제 요청 방법

다음 중 한 가지 방법으로 요청하면, 요청일로부터 30일 이내에 운영자 데이터베이스와 Google 스프레드시트에서 이용자의 정보(식별번호, 사용자 이름, 댓글·발송 기록)를 삭제하고 결과를 알려드립니다.

  • 인스타그램 @hash2n에 DM으로 "데이터 삭제 요청" 보내기
  • doldown@naver.com으로 인스타그램 아이디와 함께 삭제 요청 메일 보내기

인스타그램 설정 › 앱 및 웹사이트에서 연결을 해제하거나 댓글을 삭제해도, 이미 받은 기록은 위 요청으로 삭제됩니다.

Privacy Policy

Effective date: 2026-10-25
Service: InstaDM (Meta app name 인스타DM-IG) — automated comment replies for the Instagram account @hash2n
Operator: Hashbrown (hash2n)

This policy explains how the automated reply service (the "Service") that the operator uses on its own Instagram account @hash2n handles information. When someone comments on an @hash2n post, the Service sends them an Instagram Direct Message with the requested information, a link, or a free app promo code. The Service works only through Meta's Instagram API and never has access to anyone's Instagram password.

1. Information we process

  • Instagram-scoped user ID and username
  • Comment text, comment ID, the ID of the post commented on, and timestamp
  • Button taps in our Direct Messages and their timestamps
  • Delivery results of messages we send and, for promo code campaigns, which code was sent

We do not collect names, phone numbers, email addresses, location, or any other information not listed above.

2. How we use it

  • To send the requested information, link, or promo code by Direct Message
  • To avoid duplicate messages and to resend the same code if the same person asks again
  • To track how many promo codes were given out and to investigate delivery errors

We do not use the information for advertising, marketing, or profiling, and we never sell it.

3. Storage and retention

  • Delivery records are stored in a database on a computer managed by the operator.
  • Promo code records (code, user ID, username, time sent) are stored in the operator's Google Sheets spreadsheet.
  • Information is kept for up to 1 year after the related event ends and is then deleted, or earlier on request (see Data Deletion).

4. Sharing

  • Meta Platforms (Instagram) — to receive comment notifications and send Direct Messages. Meta's Privacy Policy applies to Meta's processing.
  • Google (Google Sheets) — to store promo code records.

We do not share information with any other third party.

5. Security

The Service only accepts requests signed by Meta, the admin dashboard is not exposed to the internet, and access tokens are kept only on the operator's computer.

6. Children

The Service is intended for people old enough to use Instagram and does not knowingly collect information from children.

7. Changes

If the information we process or our purposes change, we will update this policy and its effective date.

8. Contact

Privacy questions: doldown@naver.com · Instagram DM to @hash2n

9. Data deletion

To have your data deleted, send a Direct Message saying "data deletion request" to @hash2n on Instagram, or email doldown@naver.com with your Instagram username. We will delete your user ID, username, and comment and delivery records from our database and Google Sheets within 30 days and confirm when it is done.
