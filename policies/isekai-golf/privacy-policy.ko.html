개인정보처리방침

시행일: 2026-11-11 · 서비스: 웹 게임 『이세계골프』 (게임 주소)

회원가입·로그인이 없습니다. 이름 칸에는 게임이 추천한 별명이 자동으로 들어가며, 실명은 받지 않습니다. 다른 사람과 같이 치거나 내 라운드를 다른 사람의 '고스트'로 보여 주기 위해, 아래 표의 게임 정보만 서버와 주고받습니다.

1. 처리하는 정보

언제어떤 정보어디로
라운드(3홀)를 끝까지 쳤을 때별명, 종족, 코스 번호, 홀별 샷 궤적과 고민한 시간, 타수, 무작위 기기 문자열, 저장 시각Google Firebase(Cloud Firestore) — 다른 이용자의 게임에서 '고스트'로 재생됩니다
같이 하기(게임을 켜면 자동)별명, 종족, 티 자리, 지금 코스·홀, 샷 궤적, 타수같은 방 이용자의 기기(직접 연결) · 연결을 잇기 위한 PeerJS 공개 서버 · 직접 연결이 안 될 때 Google Firebase(중계)

무작위 기기 문자열은 같은 기기의 기록이 한 조에 두 번 나오지 않게 하려고 처음 켤 때 만드는 8글자 무작위 값으로, 기기의 실제 식별 번호가 아닙니다.

같이 하기는 기기끼리 직접 연결(WebRTC)하므로, 연결된 상대 기기에 IP 주소가 보일 수 있습니다. 혼자 치고 싶으면 주소 끝에 ?solo=1을 붙여 여세요.

광고, 분석(Analytics), 추적 도구는 쓰지 않습니다.

2. 기기에만 저장되는 정보

  • 별명(ig_name), 무작위 기기 문자열(ig_dev)
  • 최근 만난 별명(ig_met) — 다음 판에 다른 동반자를 만나게 하는 용도
  • 베스트 샷·베스트 게임 다시 보기 기록(ig_best)

3. 보관 기간과 삭제

  • 고스트 기록은 게임을 운영하는 동안 보관합니다. 지우고 싶으면 별명과 친 날짜를 적어 아래 문의처로 알려 주세요. 확인 후 지웁니다.
  • 중계 메시지는 같이 하기 중 샷을 전달하는 데만 쓰고, 게임에서 다시 쓰지 않습니다.
  • 기기에 저장된 정보는 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

4. 처리를 맡기는 곳과 국외 이전

서비스하는 일처리 위치
Google Firebase (Google LLC)고스트 기록 저장, 같이 하기 중계미국 등 Google 데이터센터
PeerJS 공개 서버 (peerjs.com)같이 하기 연결 잇기(신호 전달)국외
GitHub Pages (GitHub, Inc.)게임 파일 제공, 일반 접속 기록미국 등

정보는 게임을 켜고 위 기능을 쓸 때 인터넷으로 전송됩니다. 각 서비스의 처리 방식은 Firebase 개인정보 보호, GitHub 개인정보처리방침을 따릅니다.

5. 아동의 이용

초등학생도 이용할 수 있는 게임입니다. 별명은 자동으로 추천되며, 이름 칸에 실명·학교·연락처를 쓰지 않도록 지도해 주세요. 인앱 결제와 광고가 없습니다.

6. 방침의 변경

기능이 바뀌어 처리하는 정보가 달라지면 이 페이지에 시행일과 함께 알립니다.
