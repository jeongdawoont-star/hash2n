개인정보처리방침

시행일: 2026-11-11 · 서비스: 웹 게임 『새야 새야 · 1894~1945』 (게임 주소)

이 게임은 회원가입·로그인이 없고, 이용자의 정보를 운영자 서버로 보내지 않습니다. 게임 기록은 이용자의 기기(브라우저) 안에만 저장됩니다.

1. 수집하는 정보

운영자는 이름·연락처·학교·위치 같은 개인정보를 수집하지 않습니다. 광고, 분석(Analytics), 추적 도구도 쓰지 않습니다.

2. 기기에만 저장되는 정보

아래 정보는 브라우저의 로컬 저장소(Local Storage)에 hg_로 시작하는 이름으로 저장되며, 기기 밖으로 보내지 않습니다.

  • 랭킹: 이용자가 직접 입력한 이름(별명), 점수, 난이도, 도달 연도, 날짜
  • 명예(업적), 난이도 해금, 소리 같은 설정

랭킹 이름 칸에는 실명 대신 별명을 써 주세요. 브라우저의 사이트 데이터를 지우면 이 기록도 모두 지워집니다.

3. 외부 서비스가 처리하는 접속 정보

게임 화면을 불러오는 과정에서 아래 서비스가 일반적인 웹 접속 기록(IP 주소, 브라우저 정보, 접속 시각 등)을 처리할 수 있습니다. 운영자는 이 기록을 받지 않습니다.

서비스하는 일처리 위치
GitHub Pages (GitHub, Inc.)게임 파일 제공미국 등
jsDelivr픽셀 글꼴(Galmuri) 제공전 세계 CDN

각 서비스의 처리 방식은 GitHub 개인정보처리방침과 jsDelivr 개인정보처리방침을 따릅니다.

4. 아동의 이용

이 게임은 초등학생을 포함한 누구나 이용할 수 있는 역사 교육용 게임입니다. 개인정보를 수집하지 않으므로 별도의 법정대리인 동의 절차가 없습니다. 인앱 결제와 광고가 없습니다.

5. 정보 삭제

기기에 저장된 기록은 브라우저 설정의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

6. 방침의 변경

기능이 바뀌어 처리하는 정보가 달라지면 이 페이지에 시행일과 함께 알립니다.
